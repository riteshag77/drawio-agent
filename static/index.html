Voice commands

Press Space (or the mic button) to start/stop listening. Dictate a diagram prompt or say a command. Say help for the full list in chat. While typing in the composer, Space inserts a normal space — press Space outside the field, or again while listening, to toggle the mic.

  • Send / stop “send message”, “stop”, “stop listening”
  • Chat “clear chat”, “attach file”, “clear attachments”
  • Platform “switch to aws / gcp / azure / multi”
  • Settings “open settings”, “theme daylight”, “enable cost”
  • Diagram “download diagram”, “export png”, “copy xml”
  • Insights “apply waf”, “apply compliance”, “apply all insights”
  • Patterns “list patterns”, “use pattern 1”, “pattern serverless”

Limits: attach only opens the file picker; editing inside the draw.io canvas is mouse/keyboard only; Chrome or Edge on localhost/https.
