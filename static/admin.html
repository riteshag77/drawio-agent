Every generated view is scored 0–100 against its viewpoint rules. With validation on, a view below the target is regenerated — but only while it keeps measurably improving, so a pass that gains nothing ends the loop instead of spending another call.

Governance / house-style rules

Rules checked automatically against every generated diagram. Soft enforcement only — a failed rule nudges the AI to fix it on the spot and shows up in the diagram's Governance tab; it never blocks a diagram from being produced.

Fixed ids only — see each view's own corridor vocabulary (e.g. Security uses zone_public/zone_dmz/zone_identity/zone_partner/zone_private/zone_restricted/zone_detect).
Trust-boundary crossing is only meaningful on the Security view — its zone_public/zone_partner vocabulary has no equivalent elsewhere. On any other view, this box is silently ignored and only PII/PCI-classified flows are checked; uncheck it for a Logical/Data-flow/Network/ArchiMate-scoped rule to avoid a confusing always-passing box.
