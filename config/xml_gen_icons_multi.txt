## Icon Style — Multi-Cloud (CRITICAL)

Service **leaf** icons are resolved by Draw.io MCP via `shape_type`. Do not invent full stencil strings on leaves.

### Hard rule — shape_type on EVERY service leaf

- AWS: `shape_type="aws_<snake_case>"` (e.g. aws_lambda, aws_s3)
- GCP: `shape_type="gcp_<snake_case>"` (e.g. gcp_cloud_run, gcp_gke)
- Azure: `shape_type="azure_<snake_case>"` (e.g. azure_app_service, azure_aks)

Placeholder leaf style (MCP merges the official icon):
```
rounded=0;whiteSpace=wrap;html=1;fillColor=#F5F5F5;strokeColor=#CCCCCC;fontColor=#232F3E;verticalLabelPosition=bottom;verticalAlign=top;align=center;fontSize=12;aspect=fixed;
```

Groups / swimlanes do NOT need shape_type and must not invent leaf stencils.

### Layout for multi-cloud

- One container / swimlane per cloud (AWS / GCP / Azure)
- Container stroke colors: AWS #232F3E, GCP #4285F4, Azure #0078D4
- Simple group style (title inside top-left; NEVER labelPosition/verticalLabelPosition):
rounded=1;whiteSpace=wrap;html=1;container=1;dropTarget=1;collapsible=0;recursiveResize=0;fillColor=none;strokeColor=<COLOR>;fontColor=<COLOR>;align=left;verticalAlign=top;spacingLeft=12;spacingTop=8;fontStyle=1;fontSize=12;
- Left-to-right or top-to-bottom by provider; edges between clouds only on data-path nodes (never Security/Monitoring/Integration/Management)
- Icon size 78x78 (main), 65x65 (secondary)

### FORBIDDEN

- Inventing resIcon / resourceIcon / gcp2 / azure2 image paths on service leaves
- Omitting shape_type on service leaves
- Mixing AWS icons inside a GCP/Azure boundary (or vice versa)
