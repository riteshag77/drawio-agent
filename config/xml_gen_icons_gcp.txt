## Icon Style — GCP (CRITICAL)

Service **leaf** icons are resolved by the server via Draw.io MCP. Do not invent conflicting full stencil strings that MCP will fight.

- NEVER use mxgraph.gcp2020 (wrong / unloaded — blank icons)
- NEVER use mxgraph.aws4.resourceIcon or Azure image= paths on GCP leaves
- Icon size: 78x78 main, 65x65 secondary

## MCP shape_type — REQUIRED for every service leaf

```xml
<mxCell id="10" value="Cloud Run" shape_type="gcp_cloud_run"
  style="rounded=0;whiteSpace=wrap;html=1;fillColor=#F5F5F5;strokeColor=#CCCCCC;fontColor=#232F3E;verticalLabelPosition=bottom;verticalAlign=top;align=center;fontSize=12;aspect=fixed;"
  vertex="1" parent="<container-id>">
  <mxGeometry x="24" y="48" width="78" height="78" as="geometry" />
</mxCell>
```

Rules:
- `shape_type="gcp_<snake_case_service>"` (e.g. gcp_cloud_run, gcp_gke, gcp_cloud_sql, gcp_pubsub)
- Leaf `style` is a **placeholder only**. MCP merges the official `mxgraph.gcp2` stencil.
- Do **NOT** invent full `shape=mxgraph.gcp2.…` on leaves (optional best-effort is ignored when MCP hits)
- **Groups / containers MUST NOT** have `shape_type`

## Group Boundaries — GCP

Title **inside** top-left. NEVER use labelPosition or verticalLabelPosition.
rounded=1;whiteSpace=wrap;html=1;container=1;dropTarget=1;collapsible=0;recursiveResize=0;fillColor=none;strokeColor=#4285F4;fontColor=#4285F4;align=left;verticalAlign=top;spacingLeft=12;spacingTop=8;fontStyle=1;fontSize=12;

Common boundaries: GCP Project, VPC, Region, Zone, subnet — strokeColor=#4285F4 (or #34A853 for zone). Children y≥48.

## FORBIDDEN

- shape=mxgraph.gcp2020.*
- shape=mxgraph.aws4.resourceIcon / resIcon=mxgraph.aws4.*
- Omitting shape_type on service leaves
- shape_type on groups/containers
