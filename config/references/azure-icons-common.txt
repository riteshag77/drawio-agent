# Azure services — `shape_type` vocabulary

Copy a key verbatim into a leaf's `shape_type`. These are already in the form
the IR expects; do not derive, prefix or reformat them. A service that is not
listed still takes your best semantic guess in the same `azure_<service>`
shape — an unresolved key renders as a labelled grey placeholder, which is
strictly better than a confidently wrong icon.

Icon artwork is resolved server-side from this key — never emit a draw.io
style, image path, or stencil path.
