# Multi-cloud top services — `shape_type` vocabulary

Copy a key verbatim into a leaf's `shape_type`. Icon artwork is resolved
server-side from the key, so never emit a draw.io style, stencil path or image
path. A service that is not listed still takes your best semantic guess in the
same `<platform>_<service>` shape.

Mixing platforms in one diagram is the point of this view: use the key for the
platform each service actually belongs to.
