## Icon Style — Azure (CRITICAL)

Service **leaf** icons are resolved by the server via Draw.io MCP (`image=img/lib/azure2/…`). Do not invent conflicting stencil strings.

- NEVER use shape=mxgraph.azure2.resourceIcon or resIcon=mxgraph.azure2.* (blank / wrong)
- NEVER use mxgraph.aws4.* or mxgraph.gcp2.* / gcp2020 on Azure leaves
- Icon size: 78x78 main, 65x65 secondary
- Layout/naming/pitch/wrap: follow CORE (max 4 per row, pitch 180–220 in subnets, short under-icon labels)

## MCP shape_type — REQUIRED for every service leaf

```xml
<mxCell id="10" value="App Service" shape_type="azure_app_service"
  style="rounded=0;whiteSpace=wrap;html=1;fillColor=#F5F5F5;strokeColor=#CCCCCC;fontColor=#232F3E;verticalLabelPosition=bottom;verticalAlign=top;align=center;fontSize=12;aspect=fixed;"
  vertex="1" parent="<container-id>">
  <mxGeometry x="24" y="48" width="78" height="78" as="geometry" />
</mxCell>
```

Rules:
- `shape_type="azure_<snake_case_service>"` (e.g. azure_app_service, azure_sql_database, azure_functions, azure_key_vault)
- Leaf `style` is a **placeholder only**. MCP merges the official SVG `image=` style.
- Do **NOT** invent full `image=img/lib/azure2/…` on leaves when using MCP (placeholder + shape_type is enough)
- **Groups / containers MUST NOT** have `shape_type`

## Group Boundaries — Azure

Title **inside** top-left. NEVER use labelPosition or verticalLabelPosition.
rounded=1;whiteSpace=wrap;html=1;container=1;dropTarget=1;collapsible=0;recursiveResize=0;fillColor=none;strokeColor=#0078D4;fontColor=#0078D4;align=left;verticalAlign=top;spacingLeft=12;spacingTop=8;fontStyle=1;fontSize=12;

Common boundaries: Azure Subscription, Resource Group, VNet, Subnet, Region — strokeColor=#0078D4. Children y≥48.

## FORBIDDEN

- shape=mxgraph.azure2.resourceIcon / resIcon=mxgraph.azure2.*
- AWS or GCP stencil libraries on Azure leaves
- Omitting shape_type on service leaves
- shape_type on groups/containers
