## Icon Style — AWS (CRITICAL)

Service **leaf** icons are resolved by the server via Draw.io MCP. You must NOT invent full `mxgraph.aws4.resourceIcon` / `resIcon=` strings on leaves — that fights MCP and causes blank icons.

### MCP shape_type — REQUIRED for every service leaf

Every AWS **service** icon mxCell MUST include `shape_type`:

```xml
<mxCell id="10" value="Lambda" shape_type="aws_lambda"
  style="rounded=0;whiteSpace=wrap;html=1;fillColor=#F5F5F5;strokeColor=#CCCCCC;fontColor=#232F3E;verticalLabelPosition=bottom;verticalAlign=top;align=center;fontSize=12;aspect=fixed;"
  vertex="1" parent="<subnet-or-group-id>">
  <mxGeometry x="24" y="48" width="78" height="78" as="geometry" />
</mxCell>
```

Rules:
- `shape_type="aws_<snake_case_service>"` (e.g. `aws_lambda`, `aws_rds`, `aws_s3`, `aws_alb`, `aws_api_gateway`, `aws_dynamodb`, `aws_cloudwatch`)
- Leaf `style` is a **placeholder only** (grey box + label-under-icon). MCP merges the official stencil into it.
- Do **NOT** put `shape=mxgraph.aws4…`, `resIcon=…`, or `resourceIcon` on service leaves
- Size: 78x78 main, 65x65 secondary
- If unsure of the exact name, still emit a best-effort `shape_type` — never omit it on leaves
- **Groups / containers MUST NOT** have `shape_type`
- Layout/naming/pitch/wrap: follow CORE (max 4 per row, pitch 180–220 in subnets, short under-icon labels)

External actor leaves (Users / Client / Internet) **must** use these shape_types — do **not** invent styles or omit shape_type:

| Actor | shape_type | notes |
|-------|------------|-------|
| Users / User / People | `aws_users` | Official AWS Users resource icon (server resolves) |
| Client / Browser | `aws_client` | Official AWS Client resource icon |
| Mobile client | `aws_mobile_client` | Official AWS Mobile Client icon |

```xml
<mxCell id="users" value="Users" shape_type="aws_users"
  style="rounded=0;whiteSpace=wrap;html=1;fillColor=#F5F5F5;strokeColor=#CCCCCC;fontColor=#232F3E;verticalLabelPosition=bottom;verticalAlign=top;align=center;fontSize=12;aspect=fixed;"
  vertex="1" parent="1">
  <mxGeometry x="40" y="200" width="78" height="78" as="geometry" />
</mxCell>
```

**FORBIDDEN for Users/Client:** `shape=actor`, Cognito User Pool icons, Client VPN icons, or hand-written `resIcon=` strings — the server maps `aws_users` / `aws_client` to the correct stencil.

## Group Boundaries — AWS

Group styles are owned by the LLM (MCP does not touch them). Title **inside** top-left — NEVER use labelPosition or verticalLabelPosition:

```
points=[[0,0],[0.25,0],[0.5,0],[0.75,0],[1,0],[1,0.25],[1,0.5],[1,0.75],[1,1],[0.75,1],[0.5,1],[0.25,1],[0,1],[0,0.75],[0,0.5],[0,0.25]];outlineConnect=0;gradientColor=none;html=1;whiteSpace=wrap;fontSize=12;fontStyle=1;container=1;dropTarget=1;pointerEvents=0;collapsible=0;recursiveResize=0;shape=mxgraph.aws4.group;grIcon=mxgraph.aws4.<GROUP_ICON>;strokeColor=<COLOR>;fillColor=none;fontColor=<COLOR>;align=left;verticalAlign=top;spacingTop=4;spacingLeft=40;dashed=0;
```

## FORBIDDEN on service leaves

- Inventing `resIcon=mxgraph.aws4.*` or full resourceIcon style strings
- Using mxgraph.gcp2, mxgraph.gcp2020, or img/lib/azure2
- Omitting `shape_type` on service icons

## AWS Validation Extras

1. Every service leaf has `shape_type="aws_…"`
2. Leaf style is placeholder only (no resIcon on leaves)
3. Groups use aws4.group templates without shape_type
4. Never use GCP/Azure stencil libraries
